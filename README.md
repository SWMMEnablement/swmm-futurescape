# SWMM Futurescape

SWMM Futurescape is a browser-based playground in the SWMMEnablement collection for exploring stormwater, wastewater, and combined sewer modeling concepts. It is built on TanStack Start with TypeScript, Vite, and Bun, giving it a lightweight front end for demos and educational tools related to SWMM.
